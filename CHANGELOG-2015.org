*** Changed
- () Switch HTTP server from http-kit to Aleph

*** Fixed
- () Fix Thread leak in CSS file watcher (WatchService was not being closed)

** [2015-12-16 Wed]

*** Added
- () Experimental devtoolsFormatters support for Chrome DevTools custom object formatting (inspired by cljs-devtools)

** [2015-11-06 Fri]

*** Changed
- () Adjust for Closure library changes introduced in ClojureScript 1.7.166

*** Fixed
- () Work around http-kit bug causing memory leak when :cljs/quit is used

*** Fixed
- () Fix live reload to only reload files for modules active on the current page

** [2015-10-23 Fri]

*** Added
- () Support multiple :js-reload levels (:server, true, false) for finer-grained reload control

*** Fixed
- () Fix live reload to trigger based on compiled files rather than disk modification timestamps

*** Added
- () Introduce default-compile-callback to simplify the compilation API

- () Improve compile error reporting

- () Fix compilation error that caused an infinite recompile loop
