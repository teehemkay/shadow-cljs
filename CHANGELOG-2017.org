#+YEAR: 2017

Format: [[https://keepachangelog.com/en/1.0.0/][keepachangelog]], grouped by date.

* Changelog

** [2017-05-15 Mon]

*** Added
- () devtoolsFormatters support for node --inspect

*** Changed
- () Introduce :work-dir to decouple output from the Leiningen 'target' folder
- () Enable :emit-constants for :npm-module target
- () Rename npm package to shadow-cljs (shadow-npm name was taken)
- () Enable AOT compilation to decrease server load time

*** Fixed
- () require-file no longer generates absolute paths
- () Suppress spurious Closure compiler warnings
- () Fix several issues in :npm-module target

** [2017-05-14 Sun]

*** Added
- () Introduce :npm-module build target for producing CommonJS modules

*** Fixed
- () Fix errors getting silently lost during compilation
- () Fix cljsjs package names that Closure Compiler rejects (e.g. react-leaflet, google-analytics)

** [2017-05-13 Sat]

*** Added
- () Warn when source files appear to have been moved
- () Allow disabling the devtools WebSocket connection per target

*** Changed
- () Merge shadow-build into this repo; upgrade to Clojure 1.9.0-alpha16

** [2017-05-12 Fri]

*** Added
- () Port :module-hash-names support from shadow-build

*** Fixed
- () Fix shadow-build regression in this project

** [2017-05-03 Wed]

*** Changed

*** Fixed
- () Temporary fix for self-host/node-related issues in cljs.core handling
